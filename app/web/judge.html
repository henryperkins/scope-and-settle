  2. 2

    As designer: set the boundaries

    Start or resume your demo first. Your workspace link appears here.

    Open browser workspace

    Opens the designer role in a new tab. Keep this guide open.

    Use this run in the Figma plugin

    Paste this into the plugin and choose Connect. Figma installation instructions

    1. Open Rates, limits and client access. Select the $250 mobile-layout rate, a $250 per-quote maximum, a $500 cumulative allowance and quantity 1.
    2. Leave optional Figma authors, replies and invoice reminders off for this first test.
    3. Check the authorization box and choose Approve & enable agent. Copy the private client portal link.

    Expected: the agent is enabled within your approved limits. Example values alone do not authorize it.

  3. 3

    As client: request and approve

    1. Open the private client portal in another tab. Send “Can you add the mobile checkout?”
    2. Watch the request move through assessment to a quote. You can close the designer workspace; the hosted agent keeps working.
    3. Review the brief evidence, mobile deliverable, $250 rate-card price and exact revision. Check the consent box and choose Approve revision 1 & prepare PayPal invoice.

    Expected: an automatic quote within the approved policy, followed by a payment link after client consent. If coverage is uncertain, the agent asks for clarification or designer review. Approval is not payment.

  4. 4

    Pay and verify the same revision

    1. Open the PayPal sandbox invoice. Sign in with the dedicated personal sandbox buyer from your private testing instructions and complete the $250 sandbox payment.
    2. Return to the client portal and choose Refresh payment. Expect Paid from PayPal invoice retrieval.
    3. Return to the designer workspace and choose Check payment on the order if needed. Verify Paid, $0.00 due and the same revision.
    4. Reopen both views to verify that the agreement and payment remain saved.

    Use only the supplied sandbox buyer. These are test funds. A pending payment stays pending until PayPal confirms it.

Try native frame evidence in Figma

The browser journey above exercises automatic quoting, client approval and payment. Native frame selection and export require Figma Desktop and edit access to the exact linked file.

Loading plugin availability…

  1. Download the prebuilt plugin ZIP and extract it.
  2. In Figma Desktop, choose Plugins → Development → Import plugin from manifest. Select the extracted manifest.json, keeping code.js and ui.html beside it.
  3. Open the designated Figma file in Figma Desktop using an account with edit access. An arbitrary duplicate is not connected to this demo.
  4. Run Scope & Settle. Copy designer access from step 2, paste it into the plugin and choose Connect.
  5. Open Assess a request, select the checkout frame and choose Attach selected frame. The preview is native design evidence. This optional assessment path keeps designer review.

Background assessment uses the request and brief. It does not export a new frame while Figma is closed. If file access is unavailable, continue the browser journey.

Check a limit or recover an interrupted step

Limit check: in a separate run, approve the $250 rate with a $200 per-quote maximum. The mobile request should need designer review instead of an automatic quote. No second payment is needed.

Clarification or exception: answer in the client portal, or inspect the designer’s Needs your review card. A manual proposal is a labeled fallback, not an automatic AI result.

Interrupted invoice: approval remains saved. Retry Prepare PayPal invoice on the same order; recovery reuses that invoice.

Expired access: try Resume above. If the run was reset or revoked, start a new demo while the judging code remains valid.

Start again: Demo controls → Reset my demo clears that run and invalidates its old links. PayPal retains its sandbox invoice history. Preserve any run whose evidence you need.
